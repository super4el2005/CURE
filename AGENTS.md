# Требования к приложению Cure

## Запуск и тестирование

Агенту запрещено самостоятельно запускать и перезапускать сервер приложения
или Convex. Запрет включает `npm run dev`, `npm start`, preview-серверы,
`convex dev` и аналоги, другой порт, фоновый или дочерний процесс,
а также автоматический webServer тестового раннера. Серверы запускает
пользователь. Запрос исправить, настроить или проверить код не является
разрешением поднять сервер.

Не открывай браузер вручную для тестирования приложения и не управляй
его страницами через browser/computer-use инструменты, даже если сервер
уже запущен пользователем.

Перед запуском команды проверь цепочку npm scripts, lifecycle hooks
и конфиг тестового раннера. Сейчас `npm run check`, `npm run test:pwa`
и `npm run test:browser` запускают Playwright webServer; агенту нельзя
выполнять их в таком виде.

Разрешены проверки форматирования, линтер, TypeScript, unit-тесты, сборка
и компиляция переводов, если они не запускают серверы. Автоматические
браузерные тесты также допустимы только без запуска серверов.
Если проверка требует запрещённого действия, подготовь сценарий для
пользователя и укажи её как невыполненную. Не считай непроверенный
сценарий успешным.

## Офлайн-работа

Приложение должно поддерживать работу без интернета через TanStack DB:
локальное хранение данных, сохраняемую очередь изменений и синхронизацию
с Convex после восстановления связи.

При изменениях данных, операций пользователя, авторизации, маршрутов,
кеширования и синхронизации, затрагивающих офлайн-доступность, применяй
скилл [cure-offline-first](.agents/skills/cure-offline-first/SKILL.md).
Это требование к реализации; наличие скилла или npm-пакетов не означает,
что офлайн-поддержка уже готова.

Сохраняй соглашения проекта: TypeScript-конфиги там, где они поддерживаются,
импорты `@/...` от корня репозитория, тексты интерфейса через Lingui.
