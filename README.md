# CURE

**Clinical University Research Ecosystem** — платформа совместных исследований поликлиник и университетов.

Статус на **28 октября 2026 года**: архитектура и план разработки с проверкой стека по официальной документации. Исходного приложения и кода демоверсии нет; перечисленные функции демоверсии считаются требованиями. Приложение, инфраструктура и CI ещё не реализованы.

Документы:

- [Архитектура и границы системы](docs/architecture.md).
- [План этапов и покрытие всех 22 требований](docs/roadmap.md).
- [Проверка совместимости стека](docs/stack-verification.md).
- [Наблюдаемость, продуктовая аналитика, A/B и релизы](docs/observability-and-release.md).

Основной стек: TanStack Start + Rsbuild/Rspack, Convex + TanStack Query, TanStack DB для выбранных локальных сценариев, Mantine без кастомизации, `@gratise/i18n`, PWA, TanStack AI. По одному файлу на маршрут в плоской папке; отдельные desktop/mobile маршруты с серверным выбором варианта.

Главное открытое техническое решение — авторизация: у запрошенного Convex Auth не подтверждён готовый публичный адаптер Start SSR и полноценный MFA. Альтернатива Convex + Better Auth описана как предлагаемое изменение, а не как уже принятое решение.

Документальная проверка не заменяет сборку и интеграционные испытания. Их результаты должны стать первым результатом этапа E0.
