# Источники медицинских справочников для Cure

Дата проверки документации: 7 ноября 2026 года.

Это обзор API и наборов данных. Реализованные поисковые интеграции и их
настройки описаны в [README](../README.md#медицинские-справочники).
Перечень ниже шире подключённых источников.
Ключи не создавались, платные подписки не оформлялись, мировые справочники
не скачивались. Документация источников проверена; доступ к закрытым API,
полнота данных и возможность конкретной схемы распространения отдельно не проверены.

Полного открытого мирового реестра всех больниц/поликлиник с гарантированным

наличие медицинских исследований не доказывает наличие программы подготовки врачей.

## 1. Университеты и медицинские школы

### World Directory of Medical Schools — WDOMS

- Совместный каталог WFME и FAIMER/Intealth, специально ориентированный на
  медицинские школы с программами базовой подготовки врачей.
- Включает сведения о школах, программах, адресах, контактах и связях.
- Документированного открытого REST API на изученных страницах не найдено.
- Массовый доступ: платная годовая подписка, CSV/XML, обновление файлов ежедневно.
- Подписка и право загрузки не означают разрешение опубликовать всю базу в Cure:
  необходимо согласовать нужный сценарий использования и распространения.
- Запись в WDOMS сама по себе не является аккредитацией или одобрением школы.

Источники: [описание](https://www.wdoms.org/about/),
[выгрузки и подписка](https://www.wdoms.org/subscription/),
[условия](https://www.wdoms.org/subscription-terms/).

### Research Organization Registry — ROR

- REST: `https://api.ror.org/v2/organizations`.
- Университеты, исследовательские организации, healthcare-организации;
  названия, варианты названий, страна, местоположение, сайты, идентификаторы и связи.
- Открытая база CC0, API без регистрации согласно текущей документации.
- Для всей базы нужен data dump: через API нельзя получить больше 10 000 результатов.
- У ROR нет универсального достоверного признака «медицинский вуз» или
  «университет естественных наук». Тип `education` не решает эту задачу.
- ROR ориентирован на исследовательские организации; не является полным каталогом
  факультетов или всех медицинских учреждений.

Источники: [REST API](https://ror.readme.io/docs/rest-api),
[поля](https://ror.readme.io/docs/fields),
[покрытие и CC0](https://ror.org/about/faqs/),
[выгрузки](https://zenodo.org/communities/ror-data).

### Wikidata

- SPARQL: `https://query.wikidata.org/sparql`.
- Подходит для поиска medical schools/medical universities, профилей,
  принадлежности факультетов университетам и межъязыковых названий.
- Структурированные данные CC0; есть массовые выгрузки.
- Покрытие и заполненность свойств неоднородны; категорий недостаточно для
  доказательства полноты или действующего статуса учреждения.
- Большие запросы упираются в ограничения публичного Query Service.

Источник: [SPARQL Query Service](https://www.wikidata.org/wiki/Wikidata:SPARQL_query_service/en),
[доступ к данным](https://www.wikidata.org/wiki/Wikidata:Data_access).

### OpenAlex

- API: `https://api.openalex.org/institutions`, связанные works/topics.
- Полезен для связи организаций с научными публикациями и тематикой исследований.
- Можно строить собственную оценку медицинского/естественно-научного профиля,
  но это вычисляемый признак, а не официальный статус программы обучения.
- Доступ и бюджеты API менялись в 2026 году; для интеграции зарегистрировать ключ
  и сверить текущий тариф/лимиты. Не закладываться на старое описание «безлимитно бесплатно».

Источники: [организации](https://help.openalex.org/data/institutions/),
[аутентификация](https://help.openalex.org/api/authentication/),
[условия доступа](https://help.openalex.org/access/pricing/).

## 2. Больницы, поликлиники и другие медучреждения

### OpenStreetMap / Overpass / Geofabrik

- OSM — мировые геоданные, в том числе учреждения здравоохранения.
- Основные теги для отбора: `amenity=hospital`, `amenity=clinic`,
  `amenity=doctors`, `healthcare=hospital`, `healthcare=clinic`,
  `healthcare=doctor`. Это начальный набор: состав зависит от определения каталога.
- Встречаются координаты, адреса, телефоны, сайт, профиль помощи и часы работы.
  Поля необязательны; полнота зависит от страны и работы участников.
- Для поиска небольших выборок — Overpass API. Для мирового импорта —
  Planet/PBF или региональные выгрузки Geofabrik с обработкой на сервере.
  Не пытаться выгрузить весь мир одним запросом к публичному Overpass.
- ODbL: учитывать атрибуцию и условия распространения производных баз.
- Узлы, контуры зданий и отношения могут описывать одно учреждение;
  необходимы дедупликация и сохранение исходных OSM ID/type.

Источники: [Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API),
[Geofabrik](https://www.geofabrik.de/data/download.html),
[лицензия](https://www.openstreetmap.org/copyright).

### Healthsites.io

- API: `https://healthsites.io/api/v3/facilities/`.
- Требуется API key. Есть пагинация, фильтры по стране, территории и времени изменения.
- Форматы JSON/XML/GeoJSON и отдельные функции выгрузки.
- Источник связан с OSM: не считать его независимой второй проверкой всех OSM-записей.
- Учреждения разных типов, включая аптеки: для больниц/поликлиник нужен фильтр.
- Мировое покрытие не означает наличие каждого учреждения.

Источники: [API v3](https://healthsites.io/api/docs/),
[проект и модель данных](https://healthsites.io/).

## 3. МКБ и медицинская терминология

### WHO ICD API — основной источник

- REST API: `https://id.who.int/icd/...`.
- Покрывает ICD Foundation, ICD-11 linearizations и ICD-10.
- Облачный доступ: регистрация, OAuth 2 client credentials, заголовок `API-Version: v2`.
- Для кодов МКБ-11 использовать **MMS**, а не только Foundation:
  Foundation — многомерная система понятий, а не готовый плоский набор кодов.
- Релиз ICD-11 `2026-01` доступен в том числе на русском и английском.
- В актуальной таблице ICD-10: 2019/2016/2010 — английский,
  2008 — английский и французский. Русский ICD-10 в этой таблице не указан.
- У API есть официальные локальные варианты: Docker, Windows service, Linux service.
  Локальный сервер не равнозначен справочнику внутри браузерной PWA.
- Лицензионная страница ICD-11 указывает CC BY-ND 3.0 IGO и отдельное соглашение.
  Не приравнивать это к CC0; версию, происхождение и условия распространения сохранять.

Источники: [API](https://icd.who.int/docs/icd-api/APIDoc-Version2/),
[версии и языки](https://icd.who.int/docs/icd-api/SupportedClassifications/),
[локальная установка](https://icd.who.int/docs/icd-api/ICDAPI-LocalDeployment/),
[лицензия](https://icd.who.int/docs/icd-api/license/).

### Что означает «все диагнозы»

Импортировать можно все опубликованные рубрики/коды выбранной редакции.
МКБ включает не только диагнозы, но также симптомы, внешние причины и другие
проблемы, связанные со здоровьем. Международная ICD-10, американская ICD-10-CM
и национальные справочники нельзя смешивать как одну таблицу кодов.
Для МКБ-11 учитывать правила посткоординации: каталог базовых кодов не равен
перечню всех допустимых комбинаций.

Предлагаемый идентификатор записи: `system + release + code/URI`;
языковые наименования хранить отдельно. Межсистемные соответствия — отдельные
связи с указанием источника, а не замена кодов один к одному.

## 5. Как подключать в проекте

Предлагаемый порядок; код интеграций в рамках этого исследования не добавлен.

1. Импорт WHO ICD с зафиксированными версиями/языками и поиском по терминам.
2. Импорт ROR и связей Wikidata; медицинский профиль хранить с источником
   подтверждения. WDOMS добавить после согласования доступа и прав публикации.
3. OSM/Geofabrik как начальная географическая база учреждений, затем
   национальные источники и дедупликация. Healthsites — удобный API-доступ к
   связанному набору, а не гарантия дополнительного независимого покрытия.
4. PubMed/Europe PMC и ClinicalTrials.gov как внешние поисковые сервисы.
5. RxNorm/Orphadata, затем лицензируемые терминологии при появлении сценариев.

Для каждой импортированной записи сохранять: `source`, `sourceId`, `sourceUrl`,
`sourceVersion`, `retrievedAt`, `country`, `status`, исходное и нормализованное
названия. Историю обновлений и причины слияния дублей не терять.

Большие импорты и обновления выполнять серверными заданиями; не загружать весь
мир через браузер или одну Vercel Function. Convex может хранить нормализованный
каталог и версии импортов. В TanStack DB на устройстве сохранять выбранные
страны/регионы и нужные справочники с поиском без сети, а не обещать наличие
всей мировой базы на каждом устройстве. Права пользователя и редакционные
дополнения хранить отдельно от лицензируемого исходного набора.

Публичный read API, бесплатный просмотр сайта, bulk-доступ и право распространять
офлайн-копии — разные свойства. Перед интеграцией конкретного источника необходимо
проверить каждое из них, особенно для WDOMS, Google Places и SNOMED CT.
